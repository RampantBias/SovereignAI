Uninstalling

Uninstalling the software suite can be accomplished easily. In order to remove the active components, there must be no active Workflows. You are responsible for backing up your data.

1. Remove any active Workflows running in the cluster (for help removing Workflows, see     )
2. Using the CLI, enter the command "sovctl uninstall".
3. Review the warning and enter the 4-digit confirmation code.

The CLI will then begin uninstalling components from the cluster which may take several minutes.

In the case of failure, see more explicit directions below.
